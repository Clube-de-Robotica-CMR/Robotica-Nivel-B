# Módulo 0: Lógica e Fundamentos da Computação 🧠

Este módulo inicial estabelece a base para o pensamento computacional, explorando como os computadores processam informações e como podemos resolver problemas de forma eficiente.

## Tópicos Abordados
- **Pensamento Computacional:** A arte de resolver problemas e o conceito de algoritmos (entrada → algoritmo → saída).
- **Sistemas de Numeração:** Do unário e decimal até o sistema binário (base 2), essencial para o funcionamento dos computadores.
- **Representação de Dados:** Como letras (ASCII/Unicode), cores (RGB) e imagens são traduzidos em bits e bytes.
- **Eficiência de Algoritmos:** Comparação entre Busca Linear e Busca Binária utilizando (n vs n/2 vs log n).

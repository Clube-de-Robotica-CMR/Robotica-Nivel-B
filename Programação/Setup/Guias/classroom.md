# 🏫 Guia: GitHub Classroom

O GitHub Classroom é a nossa sala de aula virtual. É por aqui que eu vou enviar os desafios de programação e por onde você vai me entregar o seu código para correção.

---

## 🔗 Como vincular sua conta
Quando você clicar no link de um desafio pela primeira vez, o GitHub Classroom precisará de permissão para criar repositórios na sua conta:

1. **Acesse o link:** Clique no link do desafio enviado pelo professor.
2. **Autorize o App:** Clique no botão verde **"Authorize GitHub Classroom"**. Isso permite que o sistema crie uma cópia do exercício para você automaticamente.
3. **Identifique-se:** Se aparecer uma lista de nomes, procure o seu número e nome de guerra na lista da turma (Roster) para vincular sua conta do GitHub ao seu nome na escola.

---

## 🚀 Como funciona o fluxo de trabalho

Para cada tarefa nova, o processo será sempre o mesmo:

### 1. Aceitar o Desafio
Ao clicar no link de convite, o GitHub Classroom vai criar um repositório privado para você, geralmente com o nome `nome-do-desafio-seu-usuario`.

### 2. Clonar o Repositório
Dentro da página do seu repositório criado, clique no botão verde **<> Code** e copie a URL. No seu VS Code, abra o terminal e digite:
**git clone [URL_QUE_VOCÊ_COPIOU]**

### 3. Resolver e Entregar
Depois de fazer o código no VS Code, você deve salvar e enviar:
1. **git add .**
2. **git commit -m "Tarefa concluída"**
3. **git push**

---

## 💡 Dicas Importantes

* **Prazo (Deadline):** O Classroom registra o horário exato do seu último `push`. Fique atento aos prazos definidos em aula!
* **Feedback:** Em alguns desafios, eu deixarei comentários direto no seu código através de "Pull Requests" ou "Issues". Fique de olho nas notificações do seu e-mail.
* **Repositórios Privados:** Por padrão, suas tarefas são privadas. Apenas você e os professores/monitores do clube de robótica podem ver o seu código.

---
**✅ Checkpoint:** Se você conseguiu aceitar o convite e o repositório com o seu nome apareceu na sua conta do GitHub, você está oficialmente pronto para as nossas aulas!

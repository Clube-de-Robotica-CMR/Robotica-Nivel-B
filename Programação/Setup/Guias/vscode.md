## 📥 Guia de Instalação
Siga estes passos para garantir que o programa esteja pronto no seu computador:

1. **Download:** Vá ao site oficial [code.visualstudio.com](https://code.visualstudio.com/) e baixe a versão para o seu sistema (Windows/Mac/Linux).
2. **Execução:** Abra o instalador e aceite os termos.
3. **Dica de Ouro:** Durante a instalação no Windows, marque todas as caixas que dizem **"Adicionar ao Menu de Contexto"** (Add to Context Menu). Isso permite clicar com o botão direito em uma pasta e escolher "Abrir com Code".
4. **Finalizar:** Conclua a instalação e abra o VS Code.

---

## ⚙️ Guia de Configuração
Para que o VS Code entenda a nossa linguagem (C++) e fale português, precisamos de algumas extensões:

1. **Tradução:** No menu lateral esquerdo, clique no ícone de quadrados (Extensions) e pesquise por `Portuguese (Brazil)`. Instale e reinicie o programa.
2. **C++ Pack:** Pesquise por `C/C++ Extension Pack` (da Microsoft) e instale. Isso é o que vai colorir o seu código e ajudar a encontrar erros.
3. **Tema:** O visual é importante! Pesquise por temas se quiser mudar as cores do seu editor.

### 🧩 Minhas Extensões (O que eu uso):
Estas são as ferramentas que estão instaladas no meu editor para facilitar o desenvolvimento:

#### 💻 Desenvolvimento C/C++ (Essenciais):
* **C/C++ Extension Pack:** O pacote completo para programar na nossa linguagem principal.
* **C/C++ DevTools:** Ferramentas extras para facilitar o dia a dia do desenvolvedor.
* **C/C++ Themes:** Para deixar o código com cores legíveis e organizadas.
* **CMake Tools & Makefile Tools:** Essenciais para quando nossos projetos de robótica ficarem maiores e precisarem de automação na compilação.

#### 🎨 Visual e Organização:
* **Dracula Theme Official:** O tema escuro clássico que eu utilizo.
* **Symbols:** Deixa os ícones de arquivos e pastas muito mais intuitivos.
* **DotENV:** Ajuda a ler arquivos de configuração e variáveis de ambiente.

# Arrays 🧠

Nesta aula, iniciamos nossa jornada pelo Módulo 2, focando em como a linguagem C organiza informações de forma contígua na memória. Exploramos a fundo o conceito de **Arrays**, a representação binária de diferentes tipos de dados e como o computador interpreta textos e sequências de valores.

## Conceitos de Programação Explorados

**- Memória e Bytes:** Compreendemos como diferentes tipos de dados ocupam espaços distintos na memória RAM, como `char` (1 byte), `int` (4 bytes) e `long` (8 bytes).



**- Introdução aos Arrays:** Aprendemos a agrupar variáveis do mesmo tipo em uma estrutura única e sequencial, facilitando o armazenamento de listas como notas de alunos (`int scores[3]`).

**- Indexação:** O conceito de acessar elementos individuais dentro de um array através de índices, iniciando sempre na posição `0` (ex: `scores[0]`, `scores[1]`).



**- Strings como Arrays:** Descobrimos que, em C, uma `string` nada mais é do que um array de caracteres (`char`). Vimos como cada letra ocupa 1 byte e como elas são organizadas sequencialmente.

**- O Caractere NUL (\0):** A importância do terminador de string `\0`, um byte com todos os bits em zero que indica ao computador onde um texto termina na memória.



**- Arrays Multidimensionais:** Introdução à ideia de arrays de arrays, como uma lista de palavras onde cada palavra é, por si só, um array de caracteres (ex: `words[0][1]`).

**- Argumentos de Linha de Comando:** Exploramos como passar informações diretamente para o programa no momento da execução através de `int argc` e `string argv[]` na função `main`.

**- Criptografia Básica:** Uma introdução aos conceitos de segurança da informação, transformando `plaintext` em `ciphertext` através de chaves e cifras de substituição, como a Cifra de César.

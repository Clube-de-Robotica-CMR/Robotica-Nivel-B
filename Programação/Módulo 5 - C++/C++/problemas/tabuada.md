# Tabuada com C++ 🔢

Em C, utilizávamos `printf` com especificadores de formato como `%d` para exibir valores numéricos. Em C++, o `cout` identifica os tipos de dados automaticamente! Neste desafio, você vai praticar a exibição encadeada de variáveis e textos.

## Especificação
Em um arquivo chamado `tabuada.cpp`, crie um programa que execute os seguintes passos:
1. Peça ao usuário um número inteiro utilizando `cin >>`.
2. Utilizando um laço de repetição (`for` ou `while`), exiba a tabuada desse número de 1 a 10.
3. Formate a saída encadeando os valores no `cout`.
4. Garanta que o programa funcione corretamente para números positivos e negativos.

## Demonstração
```bash
$ ./tabuada
Digite um numero: 7
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```

# Fundamentos em C - Parte 2 🛠️

Nesta segunda etapa, aprofundamos nossa compreensão da linguagem C explorando a criação de abstrações personalizadas e a organização de código através de funções, além de mergulhar na estrutura de bibliotecas e arquivos de cabeçalho.

## Conceitos de Programação Explorados

**- Abstração com Funções:** Aprendemos a criar nossas próprias funções, compreendendo a relação entre **input** e **output** através de **argumentos** e **retorno** (f(x)).

**- Estrutura de uma Função:** Vimos como definir funções personalizadas, como a função `void miau(int n)`, para encapsular lógica repetitiva e tornar o código mais modular.

**- A Função main:** Entendemos que o ponto de entrada de qualquer programa em C é a função `int main(void)`, onde a execução principal ocorre e as outras funções são chamadas.

**- Prototipagem:** A importância de declarar a assinatura das funções no topo do arquivo para que o compilador reconheça sua existência antes da chamada no `main`.

**- Escopo e Parâmetros:** Como passar informações para dentro de funções através de parâmetros e como as variáveis se comportam dentro de diferentes blocos de código.

**- Bibliotecas (Libraries):** O papel fundamental das bibliotecas e o uso de arquivos de cabeçalho (`header files`) como `stdio.h` e `cs50.h` para expandir as funcionalidades da linguagem.

**- Documentação Técnica:** Introdução ao uso de manuais e documentação oficial (como o `manual.cs50.io`) para entender o funcionamento de funções como `printf` e os diversos tipos de `get_*`.

**- Boas Práticas e Design:** Discussão sobre conceitos cruciais para um código de qualidade, incluindo escopo, modularidade, legibilidade e organização lógica.
